# 码商开户与通道启用清单

## 码商开户

1. 核验码商主体、联系人和结算账户资料。
2. 在后台创建码商并保存一次性 API Key。
3. 配置单笔、单日金额和订单数限额。
4. 配置允许使用的支付通道白名单。
5. 配置回调 URL 和 HMAC 密钥，执行一次回调测试。
6. 由运营人员和财务人员分别复核后启用码商。

## 通道启用

1. 主体、服务号 AppID、商户号必须同主体绑定。
2. 校验商户号状态和 APIv2 密钥配置。
3. 调用 `/api/v1/admin/channels/:id/preflight`，确认 APIv2 密钥、AppID 绑定和回调路径全部通过。
4. 配置路由权重和金额规则，使用 `/api/v1/admin/routing/preview` 进行模拟。
5. 先以小额模拟订单观察回调、查单、退款和通道健康状态，再开放生产流量。

## 日常运营

- 每日查看通道成功率、未知订单和回调死信。
- 每日导入微信账单并处理对账差异。
- 结算单确认后再登记打款凭证。
- APIv2 密钥发生变更后重新执行通道预检。
